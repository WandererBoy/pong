# Classic Pong Game (C Language)

Классическая игра «Понг», написанная на языке **C**. Проект демонстрирует навыки работы с алгоритмами, обработки пользовательского ввода и реализации базовой игровой логики.

## Особенности проекта
* **Чистый C:** Логика игры написана без использования тяжелых сторонних фреймворков.
* **Чистая структура:** Благодаря настроенному `Makefile`, все файлы компиляции собираются в отдельную папку, не загрязняя корень проекта.

## Требования
Для сборки проекта вам понадобится компилятор `gcc` и утилита `make`.
* **Linux (Ubuntu/Debian):** `sudo apt install build-essential`
* **macOS:** `xcode-select --install`
* **Windows:** Установленный пакет MSYS2 / MinGW.

## Как собрать и запустить проект

1. Отклонить репозиторий к себе на компьютер:
   ```bash
   git clone https://github.com
   ```

2. Собрать проект (автоматически создастся папка `build` и скомпилируется исполняемый файл):
   ```bash
   make
   ```

3. Чтобы запустить игру, введите команду:
   ```bash
   ./build/pong
   ```

4. Чтобы полностью удалить папку сборки и очистить проект, выполните:
   ```bash
   make clean
   ```

## Управление
* **Левый игрок:** Клавиши `A` (вверх) и `Z` (вниз).
* **Правый игрок:** Клавиши `K` (вверх) и `M` (вниз).
* **Выход из игры:** Комбинация клавиш `Ctrl` + `C`.
